# Hobbignity

Sitio estático de ocio adaptado. Para probarlo en tu equipo, abrí `index.html` en el navegador con `styles.css`, `app.js` y toda la carpeta `assets/` en la misma estructura de carpetas.

## Publicar en GitHub Pages

1. Subí a la rama `main` el `index.html`, el CSS, el JavaScript, toda la carpeta `assets/` (incluidos logo e iconos) y el archivo `.nojekyll`.
2. En el repositorio de GitHub, abrí **Settings → Pages**.
3. En **Build and deployment**, elegí **Deploy from a branch**, seleccioná `main` y `/(root)`, y guardá.
4. Cuando termine el despliegue, abrí el enlace que aparece en **Settings → Pages**. La URL prevista es [adrian120401.github.io/Hobbignity](https://adrian120401.github.io/Hobbignity/).

El logo original `assets/logo.svg` se usa en la cabecera y el footer. Las versiones PNG e ICO se derivan de la imagen incluida en ese SVG para buscadores, vistas previas al compartir e iconos del navegador y de iOS. Si cambia el logo, regenerá esas variantes. Si cambia la URL pública, actualizá en `index.html` la URL canónica, los metadatos sociales y los datos estructurados.
